# Assets

`cars/` holds the eight player/AI car models (`<id>.glb`) and their garage
thumbnails (`<id>.png`). They are generated by the Blender script in
`tools/blender/build_cars.py` — edit the style profiles there and rebuild:

```bash
pip install bpy==4.2.0          # Blender as a Python module (Python 3.11)
python tools/blender/build_cars.py -- assets/cars --thumbs
```

Material names in the models (`Paint`, `Glass`, `Headlight`, `Taillight`,
`Reverse`, `Trim`, `Chrome`, `Tire`, `Rim`, …) are re-bound at runtime, so
paint colour, brake lights and headlights stay live. If a model fails to load
the game falls back to a built-in procedural car body.
